## 🕹️ Sobre o PyGeni
> [!IMPORTANT]
> O **PyGeni** é um framework de alto nível construído sobre o Pygame, focado em abstrair a complexidade de jogos 2D Top-Down (estilo RPG Maker).

O objetivo do framework é permitir que desenvolvedores foquem na **lógica e narrativa** do jogo, enquanto o motor cuida do *Game Loop*, cálculos de física vetorial e gerenciamento de instâncias automaticamente.

## 🚀 Como usar

### 1. Instalação (Modo Desenvolvedor)
#### Windows
```powershell
git clone [https://github.com/Alexandre-PHorz/PyGeni.git](https://github.com/Alexandre-PHorz/PyGeni.git)
cd PyGeni
pip install -e .
```
#### Linux
```bash
git clone [https://github.com/Alexandre-PHorz/PyGeni.git](https://github.com/Alexandre-PHorz/PyGeni.git)
cd PyGeni
python3-pip install -e .
```
